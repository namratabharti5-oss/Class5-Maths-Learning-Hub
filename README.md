# Maths Masti – Class 5 Mathematics Learning Hub

A colourful, responsive, browser-based learning project for Class 5 students. It introduces six mathematics areas and includes a five-question interactive quiz.

## Features
- Six topic cards: Large Numbers, Four Operations, Fractions, Measurement, Shapes & Geometry, and Data Handling.
- Topic explorer with short explanations and examples.
- Interactive multiple-choice quiz with instant feedback and score tracking.
- Responsive layout for desktop, tablet and mobile.
- No installation, database or server required.

## How to run
1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Select a topic and try the Quick Maths Challenge.

## Learning objectives
Students practise mathematical vocabulary, connect concepts to everyday examples, and check their understanding through a short quiz.

## Note
This is an educational practice resource. Topic descriptions and quiz questions are sample learning material; teachers can adapt them to the prescribed textbook and current classroom syllabus.
